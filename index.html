Data Engineering · Financial Analytics

SEC EDGAR Financial Dashboard

A common dashboard to look up any organisation by ticker and see its SEC filings and financial metrics — net income, operating costs and more — sourced from annual 10-K and quarterly 10-Q reports and mapped to US-GAAP concepts.

SEC EDGAR API→Raw→Bronze→Silver→Gold→Dashboard
  • Ingest Pull company facts and filings from the SEC EDGAR API and land the raw JSON as-is.
  • Bronze Clean and format the raw responses into a consistent, typed structure.
  • Silver Flatten the JSON into PySpark DataFrames and extract US-GAAP features and calculations.
  • Gold Compute and aggregate quarterly and annual metrics per ticker, ready to serve.
  • Orchestrate Airflow / Prefect schedules daily or monthly runs as filings and business needs change.
  • Serve Dashboard deployed on EC2, or published as static HTML via GitHub Pages.

Storage and compute run on Databricks with PySpark, chosen over Polars so the pipeline keeps scaling as the volume of filings grows.

Investment Policy Automation

An end-to-end onboarding and document automation platform for portfolio management, used by investment companies. From a user's government PAN ID and date of birth, it retrieves their legal status, risk measures, address and other application details, fills the application automatically, and generates documents based on the portfolio funds chosen. It then routes them for signing between users and authorised signatories, driven by cron jobs, user roles and status. A paper workflow that used to take weeks to a month now takes 1 day, with a human in the loop.
