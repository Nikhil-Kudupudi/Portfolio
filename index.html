Projects that tell the story

SEC EDGAR Financial Lakehouse

Data Engineering · Financial Analytics

A medallion pipeline that turns SEC filings into executive KPIs, with every dashboard number traceable to its source filing.

SEC EDGAR API→Bronze→Silver→Gold→Streamlit
How it works

An end-to-end medallion pipeline that turns SEC XBRL filings (10-K / 10-Q) into executive KPIs such as revenue, margins, free cash flow and net worth. Every number on the Streamlit dashboard traces back to its source filing, and restated figures automatically override the originals.

  • Bronze Flatten company-facts JSON to one row per reported value and write schema-enforced Parquet to S3, partitioned by fiscal year and form, with idempotent per-company reloads.
  • Silver PySpark keeps 10-K/10-Q filings, dedupes restatements (latest filed wins), classifies 3/6/9/12-month periods and assigns each value its own fiscal period, not the filing's.
  • Gold A config-driven catalog maps 21 metrics across changing us-gaap tags. Quarterly flows are derived from year-to-date values with window functions, and 15+ KPIs keep row-level lineage to the filing accession number.
  • Serve Streamlit dashboard reads gold only, with annual and quarterly views, trends, margins, cash flow, leverage and a lineage table.

Tested on Apple (about 25k fact rows, 503 us-gaap tags, FY2009 to FY2025). Next steps: dbt models for gold, orchestration, automated tests and more companies.

How it works

Paste a job description and get an honest fit score, a tailored one-page resume as both PDF and editable .docx, then one click archives the exact file you reviewed and logs the application to the Google Sheet the tracker dashboard already reads. Two LLM agents run on Cloudflare Pages Functions, while the documents render in the browser — so the bytes previewed are the bytes archived.

  • Deterministic scoring The model’s own fit score was not repeatable — three identical requests at temperature 0 came back 65 / 68 / 72, and the 72 crossed the apply threshold while the others said “maybe”. The score is now a pure function of (posting, profile): skill coverage 60, seniority fit 25, domain fit 15, with clearance and sponsorship blockers applied as a multiplier. The rationale is generated from the same numbers, so it can never contradict the score.
  • Requirement parsing A years figure only counts when it sits in requirement context, so “profitable for over 15 years” no longer reads as a 15-year requirement, and internships skip the years check entirely rather than penalising over-qualification.
  • One-page guarantee Prompt budgets first, then an authoritative clamp that truncates over-budget content and re-pins company, dates, degree and GPA verbatim from the profile, so a reworded fact can never reach the page. The PDF renderer measures its own layout and steps the type scale down before it would spill to a second page.
  • Provider resilience An OpenAI-compatible adapter retries with exponential backoff, falls through a model chain when a free-tier model stays 503 or is retired with a 404, and re-asks in plain JSON mode when a provider rejects structured output — so outages degrade instead of failing the request.
  • Tracker dashboard KPI tiles, a per-month trend and ranked breakdowns over the same sheet, with location spellings grouped into real buckets and status rendered as accessible tiles after Offer and Rejected measured a colour-blind ΔE of 4.1.
